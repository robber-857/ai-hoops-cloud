# Coach / Admin 学员姓名显示验证

## 本批范围

- 教练列表、学员详情、计划选人和课次参与记录，以及 Admin 用户和成员列表，使用资料中的姓名（现有 nickname 字段），不再用登录账号或 UUID 回退。
- 未填写姓名显示 `Name not added`，Admin 可在用户资料的 Name 字段补充。同名学员使用邮箱或手机号区分。
- Admin 添加班级成员改为姓名/联系方式搜索、分页和多选；已有有效成员不可重复选择，失败项保留以便重试。
- UUID 仍用于接口授权、路由与关联，不作为学员姓名展示。登录注册逻辑不变。
- 课次读取时解析当前姓名及联系方式；原有 roster、训练内容和历史版本不被回写。

## 验证结果

- 前端 164 tests passed；后端专用 PostgreSQL 测试库 73 tests passed。
- TypeScript、生产构建通过；lint 0 errors，15 项既有 warnings。
- 新增后端回归：更改学员姓名后当前课次和历史版本均显示新姓名，持久化 roster、内容、版本号不变。
- Playwright + 真实本地 API：两个同名合成学员按邮箱选择加入班级，刷新后读回持久化成员；无姓名学员显示提示和联系方式，页面正文不显示账号或 UUID。
- Coach 班级及学员详情验证通过；Admin 和 Coach 在 360 / 390 / 768 / 1280 / 1440px 下无页面横向溢出。
- 浏览器测试用 refresh 响应桥接合成账号的本地 token；不代表生产 cookie、真实用户或线上 UAT 已验收。
- 19 个评分模板文件与基线哈希一致。已有无关未提交工作保留。
