# P4 实际课次与参与记录验证 — 2026-09-27

## 交付范围

- 新增教练 `/coach/lessons` 独立页面，以及已发布计划的 “Record actual lesson” 入口。支持选择 active 授权班级/已发布计划建立实际课次；旧分页中的计划通过受权限保护的详情 API 定位。
- 课次独立存入 `camp_lessons`，每次保存追加 `camp_lesson_revisions`；没有复用旧视频 `training_sessions` 或评分 `analysis_reports`。
- 创建时锁定来源计划快照和当时的 active 学员名单。班级计划带入全班；个人计划仅带入对应球员。实际分钟初始为空，所有球员默认为未确认。
- 实际项目支持新增/删除、名称、分钟及备注；逐人记录全勤、缺席、提前离场、部分参与或未确认，各项目保存个人分钟和说明。
- 未确认只允许未知分钟；缺席为零；全勤逐项等于实际时长；部分参与大于零且小于全量；提前离场后不得再记录后续活动参与。个人分钟不超过项目分钟。
- 修改实际分钟/项目后要求重新核对参与情况，保留缺席标记。名单保留创建时快照，不能删除球员来掩盖缺席；新加入的班级成员不自动回填已有课次。
- 创建和保存按请求 UUID 去重，行锁与版本号防止并发覆盖；历史触发器拒绝修改/删除。可读取旧版本到编辑器，再保存为新的版本。
- 日期明确使用 Australia/Sydney；同日允许不同实际课次。此批只有教练记录，尚未发布球员课后报告或计算营养/运动消耗。
