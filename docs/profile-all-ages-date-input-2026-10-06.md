# Profile 全年龄与数字日期输入

- 体测表单与 API 解除 4–18 岁限制，适用于所有年龄。继续校验真实日期、出生日期不晚于体测日期、体测日期不晚于 Sydney 今天，以及原有身高/体重范围。
- 出生日期、体测日期、训练开始日期共用数字输入：`20120601` 自动显示为 `2012/06/01`。支持粘贴、退格、选中替换和中间编辑，手机使用数字键盘。API/数据库仍保存 ISO `2012-06-01`。
- 增量迁移 `20261006_0014` 将出生日期与体测日期的数据库约束由 `<` 改为 `<=`，允许出生当天记录；不修改历史记录。发布时先迁移、后发布 API 和前端。如已有出生当天记录，降级到旧约束会失败，不能通过删除历史记录强行降级。
- 此修改仅扩大资料记录年龄范围，不修改营养估算公式、适用年龄范围或历史视频报告。

验证：33 项前端日期/资料测试、3 项后端资料校验测试、应用 TypeScript 检查、定向 ESLint 通过。实际 Chrome 中针对源码组件的独立预览验证数字连续输入、ISO 回传、删除、清空、粘贴、中间替换、非法日期、闰日和分隔符附近退格通过。新增专用 PostgreSQL 全年龄保存/读取用例，尚未执行；尚未验证整页真实 API 保存、应用数据库迁移或线上发布。
