# P5c：菜谱维护与独立浏览界面

## 已实现

- `/admin/recipes`：草稿列表及分页；`/admin/recipes/new`、`/admin/recipes/[id]`：食品来源/名称搜索、生熟原文描述、可食用克数、做法、份数、可选图片和成品重量、过敏原审核标记、饮食说明。
- 保存后预览每份、整份、成品每 100g 和各食材贡献；保存的新菜谱跳转稳定编辑 URL，可刷新读取。未保存内容不允许发布，校验错误保留表单。
- 请求响应丢失时锁定待重试内容，使用原请求 UUID/版本重试；HTTP 校验拒绝时恢复编辑。重新加载草稿期间锁定表单，避免覆盖并发输入。刷新/关闭页面有未保存提示；侧栏客户端导航尚不提供离开确认或自动暂存。
- `/recipes`、`/recipes/[id]`：认证内已发布列表、详情、历史版本、份量预览、可选图片、缺失营养提示、过敏原状态和 AFCD 来源说明。
- 个人中心、Coach 和 Admin 导航加入 Recipes，移动菜单复用现有组件；保持 Shooting/Dribbling/Training 入口。
- 无照片时不伪造照片，无正式菜谱时展示空态；菜谱营养不是个体三餐目标，换算不写入饮食记录。
