# 小班协作与学生训练工作台 PRD

需求确认日期：2026-11-23

学生打开工作台后，可以立即看到要做的练习、已经上过的课、教练反馈及自己的训练趋势。教练在所负责的小班完成招生审核、发布视频和评阅。运营团队继续使用现有 Admin 工作台。

| 功能 | 使用和验收 |
| --- | --- |
| 小班邀请 | 教练在当前小班生成可分享的随机链接。学生打开后可注册或登录，随后向这个班提交申请。教练在本班审核，批准后才创建有效成员关系，拒绝时通知申请者。重复申请或重复批准不产生重复成员。链接有效期七天，教练可更换或撤销。 |
| 班级视频 | 教练在小班发布视频，学生从 Class videos 播放自己当前班级的视频。待审核申请者和其他班级学生无法播放。发布支持 MP4 和 WebM，每个文件上限 50 MB。 |
| 报告评语 | 教练打开有权限的学生分析报告，在 Coach feedback 留言。学生在 Notifications 阅读评语并返回该报告。学生在报告查看历史反馈。同班其他学生及公开报告分享页无权读取评语。 |
| 运营权限 | Admin 保留训练营、班级、学员、教练、目录、任务和公告等全局运营权限。系统管理员继承 Admin 能力，额外分配、撤回和管理 Admin 身份。首位系统管理员由数据库运营人员指定现有 Admin。 |
| 动作模板 | 投篮 2 项、运球 5 项、体能 10 项共用同一套选择和上传流程。动作示范、拍摄角度和测评使用同一个已发布版本。教练任务锁定所分配的动作。缺少示范视频时显示相应的图解和拍摄提示。打开已保存报告时直接展示保存的结果。 |
| AI Coach | 学生可追问篮球练习、报告评分和下一步训练。AI 参考当前学生的已发布任务、可用动作和自己近期的训练报告摘要，推荐卡片可以打开真实任务或测评。浏览器当前会话保留上下文。学生主动输入以外的身份资料、身体测量、原始视频和教练评语不进入模型上下文。 |
| 学生界面 | 侧栏按用途分组，手机可展开菜单。Overview 展示下一步训练、最近的分析报告和过去七天的已保存分析活动。Training plans 显示练习及组数、次数、时长，测评入口使用孩子能理解的动作名称。Class reports 按课次呈现，包含日期、训练时长和可用的出勤记录，保留 Daily summary。 |
| 趋势与主题 | 训练评分图按投篮、运球和训练切换，支持浏览已保存的历史评分。没有记录的日期窗口可跳到所选项目的最新评分。缺少评分的日子留空，单个记录显示为点。身体成长图按真实测量日期绘制身高、体重和 BMI，同一天使用最新修订。图表可查看记录的准确日期、数值和单位，也可展开数据表。学生、教练、Admin 和分析工作台可切换深浅主题，浏览器记住选择。 |
