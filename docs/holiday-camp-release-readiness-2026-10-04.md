## 证据边界

推送成功只证明 GitHub 保存了代码，不代表 CI、真实用户 UAT 或正式上线。官方 AFCD 工作簿及数据库 fixtures 需要单独准备：普通 clone 中未提供这些输入时，相应测试会跳过，不能把绿色的少量测试解释为完整回归。

预览指纹防止发布复核读取到的输入与人工预览不一致；旧报告仍固定在该版本审核过的快照，不追随后续资料变化。
